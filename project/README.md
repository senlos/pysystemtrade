# Local project documentation

This directory contains project documentation layered on top of upstream
pysystemtrade. Preserve the upstream source and runtime layout.

- `state/` records current project state.
- `decisions/` records project decisions.
- `policies/` contains explicit operating and test policies.

Generated non-runtime evidence from local work belongs in `project/data/`.
`project/notebooks/` is reserved for interactive learning and research; it has no
defined curriculum or contents yet.
